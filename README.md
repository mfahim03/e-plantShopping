# Paradise Nursery

Paradise Nursery is a responsive plant shop demo built with React, React Router, and Redux Toolkit. Browse houseplants by category, add plants to a shared cart, adjust quantities, and review the order total.

## Getting started

```bash
npm install
npm run dev
```

## Features

- Welcome page with a greenhouse background and company introduction
- Three houseplant categories with six plants in each category
- Redux powered cart with live item count, quantity controls, and totals
- Responsive layout for desktop and mobile

## Project structure

- `src/App.jsx` – landing page and application routes
- `src/App.css` – global styles and landing page background image
- `src/AboutUs.jsx` – company story
- `src/CartSlice.jsx` – Redux cart state and selectors
- `src/ProductList.jsx` – categorized plant catalog
- `src/CartItem.jsx` – shopping cart page
